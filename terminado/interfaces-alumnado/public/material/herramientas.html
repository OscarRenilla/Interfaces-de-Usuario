Herramientas y limitaciones

RA2 a: compara Web Speech API (voz), MediaPipe (modelos de manos, cuerpo y cara), TensorFlow.js y Teachable Machine (aprendizaje automatico). No se entrena un modelo en estos ejercicios.

RA3 a: compara DevTools, Web Components, Storybook, Vitest y las pruebas Node incluidas. Redacta una tabla propia: utilidad, requisito y alternativa para cada herramienta.

Chrome/Edge: la disponibilidad de voz depende de version, sistema, idioma y servicios de red. No se garantiza en todos los equipos. Puede enviar audio al proveedor del navegador. No dictes datos sensibles.

La camara necesita permiso y localhost o HTTPS. MediaPipe descarga modelos desde Internet. R3 compara pixeles: NO identifica un cuerpo humano. R7/E7 hacen una superposicion 2D ligada a la mano, no realidad aumentada espacial 3D con WebXR. Comprueba con el docente si esta evidencia cubre su criterio RA2 f.
